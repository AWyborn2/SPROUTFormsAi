BEFORE YOU START
1

Work through each module

Five modules, unlocked in order from the Module Menu. Finish one and you return to the menu for the next.

2

Open the interactive cards

Some slides have cards to flip, tick or expand. Open every one — Next stays locked until you do.

3

Watch for the green tick

A slide ticks green once it is read or fully explored, then Next lights up. Finish all five modules to start your assessment.
